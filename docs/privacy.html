Privacy

Usage Monitor for Codex is designed as a local Windows utility. The current release contains no project-operated telemetry, analytics, advertising, or behavioral tracking.

Local data

The application may store Codex usage percentages, reset times, minimal account or plan metadata, configuration, confirmed and pending notification state, widget position, heartbeats, and diagnostic logs on the user's computer.

Data not collected

The application is not designed to collect prompts, conversations, repository contents, browser cookies, session cookies, passwords, or authentication tokens.

Network use

The notifier communicates with the locally installed Codex App Server. Codex itself may contact OpenAI for authentication and usage information. Opening the project website or GitHub release page contacts those services only when the user chooses to open them.

Deletion

Local notifier data can be removed by uninstalling the notifier and deleting its data folder after its processes and Scheduled Tasks have stopped.

Support

Never place credentials, tokens, account identifiers, personal data, or unredacted logs in public issues. Use the repository security policy for sensitive reports.
