Local by design

Privacy

The monitor contains no project-operated telemetry, analytics, advertising, tracking scripts, or behavioral profiling.

Data stored locally

Usage percentages, reset times, minimal profile metadata, settings, confirmed state, notification state, local history, bounded logs, and update transaction state may be stored on the user's PC.

Credentials

Codex authentication remains managed by the installed Codex CLI. Optional email credentials are protected using Windows security facilities and are not written to ordinary settings or diagnostics.

Data not collected

The application is not designed to collect prompts, conversations, repository contents, browser cookies, ChatGPT passwords, or Codex authentication tokens.

Network activity

The app communicates with the local Codex App Server, user-configured email services, and a trusted update feed when those optional features are enabled.

Deletion

History retention is configurable. For a portable ZIP, exit the app from the notification area and delete the extracted folder. The ZIP contains portable.mode, so its settings, history, logs, and update state are in that folder. For MSIX, use Windows Settings > Apps > Installed apps > Codex Usage Monitor > Uninstall. Windows controls the package data cleanup.
