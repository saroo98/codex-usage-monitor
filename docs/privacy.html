Policy

Privacy

Last updated: August 5, 2026

Local processing

The application may store Codex limit percentages, reset times, account and workspace identifiers needed for isolation, settings, widget position, notification receipts, and optional history on the user's Windows device.

Data not collected

The application is not designed to collect prompts, conversations, repository contents, browser cookies, session cookies, or authentication tokens. Telemetry, analytics, advertising, and behavioral tracking are disabled by default.

Network activity

  • Codex usage data is obtained through the locally installed Codex App Server.
  • Optional update checks may contact this repository's GitHub Releases endpoint.
  • Optional email alerts contact only the provider configured by the user and send only the information needed for the alert.

Credentials

Email credentials or provider tokens, when configured, must use Windows-protected credential storage. They must not be written to logs, settings, diagnostics, or the source repository.

Deletion

Users can remove local history and settings from the application or delete its local application-data folder after exiting the program.

Third parties

OpenAI Codex, GitHub, Microsoft, Google, and any selected email provider operate under their own policies.

Contact

Use the repository's public issue tracker only for questions containing no personal data or credentials. Security-sensitive matters must follow the security policy.
