Support

Public support is handled through GitHub Issues.

Before reporting a problem

  • Install the latest official stable release.
  • Use the signed MSIX for the normal installation, or the x64 self-contained Portable ZIP for a portable install.
  • Search existing open and closed issues.
  • Restart Codex and the monitor.
  • Reproduce the issue once and export only redacted diagnostics when useful.

Include

  • Application version and installation type
  • Windows version and architecture
  • Codex version
  • Clear reproduction steps
  • Expected and actual behavior

Never include

  • Passwords, tokens, cookies, OAuth codes, certificates, or signing material
  • Full email addresses or account identifiers
  • Prompt or conversation content
  • Private repository paths or unredacted logs
