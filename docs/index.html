Small surface. Complete control.

Designed as an unobtrusive Windows companion with native behavior, clear account isolation, and low idle resource use.

Responsive widgets

Useful alerts

Desktop-native

Tray controls, opacity, themes, edge snapping, click-through mode, and per-monitor positioning.

Dynamic limits

No telemetry by default. No prompt, conversation, browser-cookie, or repository-content collection.
