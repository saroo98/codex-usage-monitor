Compact monitoring with visible failure states.

The current public release is a Python and PowerShell application for Windows 10 and Windows 11.

Live widget

A small WPF desktop widget shows the confirmed remaining percentage and reset countdown.

Reset alerts

A modern popup is backed by toast, tray, sound, and taskbar notification channels.

Structured data

Reads Codex rate limits through App Server methods instead of scraping a browser page.

Reliability checks

Confirms apparent increases, rejects regressed windows, and preserves pending alerts across restarts.

Local-first privacy

No project telemetry and no collection of prompts, conversations, cookies, passwords, or tokens.

Open release process

MIT source, public tests, deterministic ZIP packaging, SHA-256 checksums, and build attestations.

Download from the official repository

Official release archives and checksums are published through GitHub. The current package requires Python 3.10 or newer and a signed-in Codex CLI installation.
