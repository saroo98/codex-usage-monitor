Release integrity

Builds you can inspect.

Official production artifacts must come from a reviewed public commit and the protected release workflow. Manual binary substitution is not allowed.

Required checks

The workflow restores locked dependencies, builds and tests x64 and Arm64, creates deterministic portable archives, verifies package contents and paths, produces SHA-256 checksums and an SBOM, and reopens every artifact.

Signing

Production Windows packages and update metadata must use the approved signing identity and trust anchor. Development certificates are never represented as public production trust.

Verify a download

Download only from the official GitHub Releases page. Compare the SHA-256 value with SHA256SUMS.txt and verify the Authenticode signer for signed packages.
