Release integrity

Verify what you download.

The public Windows files are not Authenticode-signed. Windows can show an unverified or unknown publisher. Do not disable Windows security controls.

Independent checks

SHA256SUMS.txt binds asset names to bytes. Deterministic portable ZIP checks detect build drift. bom.json provides a CycloneDX dependency inventory. GitHub artifact attestations bind assets to the tagged GitHub Actions workflow.

GitHub attestations prove build provenance; they do not make an unsigned Windows publisher trusted. The Ed25519-signed update manifest authenticates automatic updates separately from Windows publisher identity.

Safe starting point

Download only from the official GitHub Releases page. Check the repository owner, tag, filename, SHA-256 value, and attestation before running a file.
