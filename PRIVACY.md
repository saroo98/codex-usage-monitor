# Privacy Policy

Last updated: August 5, 2026

Usage Monitor for Codex is a local Windows utility maintained by [@saroo98](https://github.com/saroo98).

## Data processed locally

The application may read and store locally:

- Codex usage-limit percentages and reset times
- Codex account and workspace identifiers needed to prevent cross-account data mixing
- Application settings, widget position, notification receipts, and optional usage history
- Redacted diagnostic information generated at the user's request

The application is not designed to collect prompts, conversations, repository contents, browser cookies, session cookies, or authentication tokens.

## Network activity

Network access is limited to features selected by the user or required by Codex itself:

- Codex usage data is obtained through the locally installed Codex App Server.
- Optional update checks may contact this repository's GitHub Releases endpoint.
- Optional email alerts contact only the email provider configured by the user and send only the alert content required for delivery.

## Telemetry

Telemetry, analytics, advertising, and behavioral tracking are disabled by default. The project does not sell user data.

## Credentials

Email passwords or provider tokens, when configured, must be stored through Windows-protected credential storage. They must not be written to logs, settings files, support bundles, or this repository.

## Local retention and deletion

Users can delete local history and settings from the application or by removing its local application-data folder after exiting the program. Uninstalling the application does not control data retained independently by Codex, GitHub, Microsoft, Google, or an email provider.

## Third-party services

Optional or required integrations are governed by their own policies, including OpenAI Codex, GitHub, Microsoft, Google, and the user's selected email provider.

## Support

Privacy questions may be opened as a public issue only when they contain no personal data, credentials, logs, or account identifiers. For sensitive security matters, follow [SECURITY.md](SECURITY.md).

## Changes

Material policy changes will be recorded in this repository's public history.
