# Contributing

Contributions must be public, reviewable, and limited to the application, tests, documentation, website, or release infrastructure.

## Requirements

- Do not commit credentials, certificates, tokens, personal data, private planning documents, roadmaps, internal notes, or unpublished artifacts.
- Keep changes focused and explain user-visible behavior.
- Add or update tests for functional changes.
- Preserve privacy, accessibility, low-resource operation, and account isolation.
- Report security issues through [SECURITY.md](SECURITY.md).

## Development environment

- Windows 10 or Windows 11
- Current supported .NET SDK declared by the repository
- Visual Studio, Rider, or the `dotnet` CLI
- A local Codex installation for integration testing

## Pull requests

1. Fork the repository and create a focused branch.
2. Build and run the applicable tests.
3. Confirm no generated binaries, secrets, local state, or private material are included.
4. Open a pull request using the repository template.
5. Address review feedback before merge.
